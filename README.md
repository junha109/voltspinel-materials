# 볼트스피넬 머티리얼즈 (가상 기업) 홈페이지

「AI 기반 문제 해결」 수업 프로젝트용 **가상 기업** 홈페이지입니다. 실제 회사가 아닙니다.

- 회사 홈페이지: 고전압 LNMO(LiNi0.5Mn1.5O4) 양극재를 연구하는 가상의 연구소 규모 회사
- 「임직원 로그인」: 가상 사내 포털 「볼트넷」 데모 (데모 계정이 미리 들어 있고, 입력값은 어디에도 전송되지 않음)
- XRD 데이터는 공개 결정구조와 문헌 경향으로 생성한 합성 데이터이며, 실측 데이터나 특정 기관의 데이터를 정답으로 쓰지 않았습니다.
  측정 조건(Mn 형광 배경 · 계수 수준 · 시료 높이 오차)만 공개 실측 자료(A-Lab Precursor Genome, CC BY 4.0)의 통계에 맞췄습니다.
- 사내 자료(배치 조회 · 파일서버)는 2026년 3분기 합성 배치 406건(VS26Q3-001–406)의 2분 · 10분 스캔과 정밀 재분석 값입니다.
- 홈페이지 구성은 실제 배터리 기업 홈페이지의 일반적인 형식을 참고했고, 로고 · 그림 · 문구는 새로 만들었습니다.

빌드 없이 정적 파일(`index.html` + `files/`)로 동작합니다.
