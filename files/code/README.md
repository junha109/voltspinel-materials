# VoltSpinel Materials — 가상 기업 AI 품질관리 프로젝트

수업 과제 「가상 기업에서의 AI 기반 문제 해결」용 프로젝트. 고전압 LNMO(LiNi0.5Mn1.5O4) 양극재 회사의
QC XRD에서 rock-salt 불순물 피크가 주상 피크와 Δ2θ 0.6–0.9° 이내로 겹쳐 기존 분석 프로그램이
정량하지 못하는 문제를 다룬다. DRX·실측 데이터는 사용하지 않았다.

## 구성
| 파일 | 역할 |
|---|---|
| `src/lnmo_xrd.py` | 3상 결정구조(무질서 Fd-3m / 규칙 P4_332 / rock-salt Fm-3m) + Cu Kα1/α2 XRD 시뮬레이터 |
| `src/generate_dataset.py` | 가상 공정 모델(소성온도·후어닐링·냉각 → 정답 상태) + QC 배치 406개 생성 |
| `src/baseline_searchmatch.py` | '기존 방식' 재현: 피크 리스트 search-match (DB NiO 참조선, 2θ 창 매칭) |
| `data/patterns/*.xy` | 배치별 2θ–counts (10–90°, 0.02° step) |
| `data/labels.csv` | 레시피 + 정답(rock-salt wt%, 규칙상 분율, 격자, 결정자, 사양 판정) |
| `data/components/*.npz` | 대표 배치 46개의 상별 성분(그림·검증용) |
| `data/baseline_*.json/csv` | 기존 방식 결과 |
| `site/index.html` | 회사 홈페이지 (데이터 내장 단일 HTML) |

## 정답 설정 (가상 공정 모델)
- rock-salt0 = 0.2 + 6.0 / (1 + exp(-(T-900)/30)) wt%, 후어닐링 t시간 뒤 × exp(-t/18)
- 규칙상 분율 f = f0 + (1-f0)(1-exp(-t/20)), f0 = 0.25(서냉) / 0.05(급냉), T ≥ 950 °C면 f0×0.6
- 출하 사양: rock-salt ≤ 1.5 wt%. 제품 유형: f < 0.3 무질서형(VS-5D), 0.3–0.7 부분규칙형(VS-5H), > 0.7 규칙형(VS-5O)
- 계수는 문헌 경향(700 °C 규칙화, 900 °C 소성 시 산소 손실과 rock-salt, 800 °C 이상 1→4 %)을 재현하도록 정한 가상 값

검출되지 않음. 규칙상 초격자 피크는 최강선의 약 0.3 %.
