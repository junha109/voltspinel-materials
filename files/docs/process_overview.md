# LNMO 고상법 2단 열처리 공정 개요

볼트스피넬 머티리얼즈 공정개발팀 (가상 기업 자료)

| 단계 | 조건 | 일어나는 일 | 관리 포인트 |
|---|---|---|---|
| 1. 전구체 혼합 | Li2CO3, NiO, MnO2 볼밀 혼합 | 화학량론 혼합 | Li 과잉 0–2 % |
| 2. 1차 소성 | 800–1000 °C, 공기, 10 h | 스피넬 결정 성장. 고온일수록 산소가 빠지며 Mn3+ 생성, Ni이 많은 rock-salt(LixNi1-xO) 석출, Ni/Mn 무질서화 | 온도가 높을수록 결정성↑ / 불순물↑ |
| 3. 후어닐링 | 700 °C, 0–60 h | 산소 재흡수, rock-salt 재고용, Ni/Mn 규칙화(P4_332) 진행 | 시간이 길수록 불순물↓ / 규칙화↑ |
| 4. 냉각 | 서냉 또는 급냉 | 서냉 시 규칙화 일부 진행 | 제품 목표에 맞춰 선택 (VS-5D 급냉 · VS-5O 서냉) |
| 5. QC | Cu Kα XRD (SOP-QC-XRD-03) | rock-salt 함량·규칙화 판정 | 샘플 출하 사양 rock-salt ≤ 1.5 wt% |

## 공정 변수와 품질 지표의 관계 (사내 경험식, 2025)
- rock-salt (wt%) ≈ [0.2 + 6.0 / (1 + exp(-(T - 900)/30))] × exp(-t_anneal / 18)
- 규칙상 분율 ≈ f0 + (1 - f0)(1 - exp(-t_anneal / 20)),  f0 = 0.25 (서냉) / 0.05 (급냉), 1차 소성 ≥ 950 °C면 f0 × 0.6
- 조성이 벗어나면 rock-salt가 늘어난다: × exp(6 · Ni 과잉 + 4 · Li 부족) (몰비 기준). Li는 880 °C 위에서 조금씩 휘발한다.
- 소성로별 실제 온도 차이 (2026-07 열전대 점검): 1호기 0 · 2호기 +3.5 · 3호기 −2.5 °C

## 참고 문헌 (공정 경향)
- J. Mater. Chem. A (2023) — Ni/Mn 규칙화는 약 700 °C 소성에서 진행
- J. Mater. Chem. A (2025) — 900 °C 1차 소성 시 산소 손실과 rock-salt 불순물, 저온 재어닐링으로 회복
- ECS Meeting (2015) — 800 °C 이상에서 무질서상 우세, LixNi1-xO 1 → 4 %

> 경험식의 계수는 수업 프로젝트용 가상 값입니다.
