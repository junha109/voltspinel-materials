# SOP-QC-XRD-03 양극재 배치 XRD 측정 및 판정 절차

볼트스피넬 머티리얼즈 분석평가팀 · Rev. 4 (2026-10, 가상 기업 자료)

## 1. 측정 조건
| 항목 | 조건 |
|---|---|
| 장비 | 벤치탑 분말 XRD 2대, Cu Kα (Kα1 1.54056 Å / Kα2 1.54439 Å), 측각기 반경 150 mm |
| 검출기 설정 | XRD-1 기본 설정 (Mn 형광 배경이 스피넬 (400) 높이의 0.6–1.2배) · XRD-2 형광 억제 설정 (0.12–0.25배) |
| 측정 범위 | 2θ 10–90°, step 0.02° |
| 스캔 시간 | 일상 QC 2 min / 정밀 10 min (같은 시료, 계수 약 5배) |
| 시료 | 배치당 1 g, 백필 홀더 (시료 높이 오차 약 ±0.08 mm) |

## 2. 판정 절차 (현행)
1. 상용 분석 프로그램의 search-match로 상 동정 (DB 참조: LNMO, NiO bunsenite)
2. rock-salt 참조선 (111) 37.25°, (200) 43.28° 근처에 독립 피크가 검출되면 "불순물 검출"
3. 불순물 검출 시 정밀 스캔(10 min) 후 숙련 분석자가 Rietveld 정련으로 wt% 산출
4. 규칙화: 규칙상 전용 초격자 피크 (210) 24.3°, (211) 26.7°, (320) 39.7° 확인 — 일상 QC 스캔에서는 판정 보류

## 3. 알려진 문제 (2026-10 분석평가팀 메모)
- rock-salt 피크는 스피넬 (222) 38.1°, (400) 44.3°에서 0.6–0.9° 떨어져 있어 저함량에서는 어깨로만 보임
- 실제 불순물 LixNi1-xO는 DB NiO보다 격자가 작아 피크가 0.15–0.3° 고각 쪽으로 이동
- Cu Kα에서 Mn이 형광을 내 배경이 높음. 특히 XRD-1에서 어깨가 배경 잡음에 묻힘
- Rietveld 결과가 분석자마다 다름 (같은 배치 1.3 / 1.9 / 2.4 wt%)
- 규칙상과 무질서상 패턴이 거의 같아 일상 QC로는 제품 유형(VS-5D/H/O) 판정 불가
